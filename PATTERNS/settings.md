# Settings

Settings are a calm, scannable form — not a second app.

**Code:** Matrix Settings sheet tabs · Site account / activate surfaces

---

## MATRIX reference structure

Tabs: **General** · **Interface** · **Account** · **About**

| Tab | Content |
|-----|---------|
| General | Sample rate, format, buffer, open at login, feedback protection |
| Interface | Appearance (System / White / Dark), patch grid zoom |
| Account | Quadra ID, offline `.qkey`, HWID |
| About | Brand, version, support |

Use catalog controls (`SurfaceChip`, `QuadraArm`, system `Slider` with tint). Card titles use Title 3; descriptions use Callout.

---

## Rules

### Do

- Group related controls; one section = one concern.
- Persist appearance and zoom in session state.
- Offer System appearance that follows the OS.

### Don’t

- Don’t bury quit/license destruction without confirmation.
- Don’t mix marketing hero layouts into Settings.
- Don’t introduce untinted system blue prominent buttons.
